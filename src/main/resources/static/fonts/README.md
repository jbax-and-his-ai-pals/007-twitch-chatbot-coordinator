# Bundled font

`Web437_IBM_VGA_8x16.woff` is the "Web437 IBM VGA 8x16" web font from **The Ultimate Oldschool PC Font Pack**
v2.2 by VileR (<https://int10h.org/oldschool-pc-fonts/>), a faithful pixel copy of the IBM VGA ROM text font
that DOS drew its text with. It is used by the retro control-panel themes (`theme-retro.css`).
